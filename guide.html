What it does

In Stardew Valley 1.6, a Mushroom Log produces mushrooms every few days. What it produces depends on the trees around it. More trees mean more mushrooms and better quality, and the tree types decide which mushrooms you get. The trees can also be tapped for syrups at the same time.

The planner takes a rectangular plot of land and looks for the arrangement of logs, trees and walkways that earns the most gold per day. The result includes:

  • a color-coded map of the layout with a legend,
  • a shopping list of logs (and the Hardwood and Moss to craft them), trees, seeds and tappers,
  • expected mushrooms by type and quality, plus tapper products,
  • earnings per day, per 28-day season and per 112-day year.

You can ask for a minimum share of one mushroom type (for example, "at least 55% Morels"), include or leave out tapping, and require walkways that fit how you play.

New in version 3: a tile size study page with charts of which repeating-tile size earns the most, and every best layout drawn out.

New in version 2: repeating tiles. Instead of one fixed plot, the planner can design a small pattern (a tile) that you copy side by side as you craft more logs. Trees in one copy feed the logs in the next, and walkways join up across copies, so the planner designs the tile for how it performs when it's surrounded by copies of itself. See Repeating tile and how it's calculated.

In this guide a square or a tile in the older sections means one spot on the grid. In the repeating-tile sections, tile means the whole repeating pattern and square means one spot in it.

Quick start

  1. Choose Fixed plot or Repeating tile at the top. For a fixed plot, enter its Width and Height. For a repeating tile, enter the tile size or tick Find the best tile size.
  2. Tick the trees you can plant (leave Mystic off if you don't have Mystic Tree Seeds yet).
  3. Optionally choose a preferred mushroom and a minimum share.
  4. Set the tapping and walkway options to match your game.
  5. Press Generate optimal layout. The map updates live while it searches.
  6. Hover over tiles to inspect them, or pick a brush and edit the layout by hand. The totals update right away.
Settings like tapping, moss and rain update the numbers straight away, but they don't rearrange the layout. After changing a setting, press Generate again to get a layout optimized for it.

Plot & walkways

Width (X) / Height (Y)The plot size in tiles, 3 to 64 each. Changing it keeps whatever overlaps the old layout, then leaves the rest empty until you generate again.
Leave walkways so you can reach every log and tapped tree When on, a log or tapped tree only counts if you can stand next to it on a walkway (an empty tile) that you can reach. Normally "next to" means any of the 8 surrounding tiles, since you can harvest diagonally with a mouse. The plot's outer edge is treated as open ground, so items on the edge count as reachable, and a walkway counts if it touches the edge anywhere. When off, the planner ignores access entirely and packs the plot as densely as possible.
Harvest only from walkways, never from outside the plot's edge Use this when the land around the plot is blocked (fences, buildings, crops), or when you simply want to do all your collecting from inside the plot. You can still walk in from any edge, but a log or tapped tree on the edge counts only if a walkway tile inside the plot is beside it. This is always on when the continuous-path option is on.
Make the walkway one continuous path with a single entrance Treats the plot as fenced in. Only one connected walkway network counts, and it has to touch the Entrance side you choose (Bottom, Top, Left, Right, or Any edge). Items on the plot's edge are no longer reachable from outside. The entrance is marked on the map with a green arrow. Empty tiles that aren't part of the path are drawn dotted as "unused". The path doesn't have to come out the other side. It can branch and dead-end freely.
Console mode For controller players, who can only interact with the tile they're facing. Every log must have a walkway directly beside it (up, down, left or right). Diagonal tiles no longer count. Apply console mode to tapped trees too applies the same rule to trees with tappers. Trees that fail it just aren't tapped; they still help nearby logs.

Repeating tile

These settings appear when you choose Repeating tile. The walkway options above still apply, with the changes noted here.

Tile width / Tile heightThe size of the repeating pattern in squares, 2 to 16 each.
Find the best tile sizeTries every tile size from 2×2 up to the width and height you entered. It keeps the one that earns the most gold per square of land, then spends the rest of the search time improving it. The map title says "best size found" when this was used. Larger limits test more sizes, so each size gets a shorter search; 8×8 is a good limit for Normal or Thorough.
Preview: tiles across / downHow many copies to draw on the map and total up in the "Preview" figure, 1 to 12 each way. This only changes the display and totals, not the tile.
Walkways in a repeating tile A large group of copies has no outside edge near its middle, so walkways must run off the tile's edges and join the walkways in the next copy. A walkway that stays inside one tile counts as unreachable. With Make all walkways one connected network across every tile (the repeating-tile version of the continuous-path option), the walkways must join up both across and down, so every tile connects to every other. Without it, walkways can be separate strips, each running off the edge of the finished group. The entrance-side setting doesn't apply. Harvest only from walkways applies to the outer edge of the finished group.

Mushroom target

Preferred mushroom "None" maximizes gold regardless of the mix. Pick a mushroom to require a minimum share of all mushrooms produced.
Minimum share The percentage of all mushrooms that must be the preferred type. Logs always mix in random mushrooms, so 100% is impossible. The hint under the slider shows the highest share you can get with the trees you've allowed (see Target share). If you ask for more, the planner gets as close as it can and tells you. Meeting the target comes before earning gold: the planner will give up gold to reach it.

Tapping

Tapper typeA regular Tapper or a Heavy Tapper (about twice as fast).
Tapper professionThe Foraging level-10 profession: Maple Syrup, Oak Resin, Pine Tar and Mystic Syrup sell for 25% more. It doesn't affect Sap or mushrooms.

Conditions

Share of trees with mossThe average share of grown Oak, Maple and Pine trees that have moss on them. Mossy trees count twice for quality. It doesn't change the number or type of mushrooms.
Rainy daysHow often it rains. Rain makes a log finish a day sooner, which the planner estimates (see Timing).
Search timeHow long the optimizer searches: 2, 5 or 12 seconds. Longer searches find better layouts on average, which matters most for large plots and when walkway options are on. Each run is random, so running again can give a slightly different result.

Reading the results

The map

  • 🍄 Mushroom Log; O / M / P / Y / H Oak, Maple, Pine, Mystic, Mahogany; s stunted sapling.
  • A yellow dot in a tree's corner means it has a tapper.
  • Walkway tiles are shaded. Dotted tiles are empty ground you can't reach from the walkway. The green arrow is the entrance (continuous-path mode only).
  • A red outline means you can't reach the item, so it isn't counted (logs) or isn't tapped (trees).
  • Red stripes mean a tile breaks the tree-spacing rules (only possible after editing by hand).
  • Repeating tile: the map shows the preview group. The bright top-left copy is the pattern, and the dimmed copies show how it repeats. Gold lines mark the tile edges. Painting any copy changes the pattern, so every copy updates.

Inspecting and editing

With the Inspect brush, hovering over a log highlights its 7×7 range and shows its tree count, mushrooms per harvest, mushroom mix, quality odds and gold per day. Hovering over a tree shows what it adds to logs and what its tapper makes. Pick any other brush and click or drag to paint tiles. Everything is recalculated immediately.

The panels

  • Headline figures: gold per day, season and year (split into mushrooms and tapping), mushrooms per season, and your target's share if you set one.
  • What you need: counts of logs (with Hardwood and Moss), each tree type (with its seed), saplings, tappers and walkway tiles.
  • Mushroom yield: share, per-season and per-year counts, and yearly gold by type, plus the average quality mix.
  • Tapping yield: for each product, the number of trees, days per product, per-season count and yearly gold.

Repeating-tile panels

  • Per tile: gold per day and per year for one tile surrounded by copies on every side, what the tile holds, and the preview group's total. The shopping list and the yield tables are also per tile, so multiply by the number of copies you plan to place.
  • Growing your farm: the logs, trees and gold per day for groups of 1, 2, 4, 6, 9, 16, 25 and 36 copies (plus your preview size), with gold per tile. Small groups earn less per tile because their outer copies have fewer neighbors. The per-tile figure rises toward the fully surrounded value as the group grows. Logs on the outer edge whose walkway would sit in a copy you haven't placed yet are listed as unreachable.
  • Hovering a log in the preview shows what it earns where it sits, and what the same log earns with copies on every side.

How it's calculated

All figures are long-run averages. The planner doesn't simulate random harvests. It works out the expected value of each random roll the game makes. Mechanics follow the Stardew Valley wiki (see Sources).

1. Which mushroom: the pool

Let n be the number of trees in range. This counts every tree in range, grown or not, including stunted saplings. At each harvest the game builds a list (the "pool") and picks one entry at random:

  • Random entries: max(1, floor(0.75 × n)) of them. Each is Common 80.75%, Red 14.25% or Purple 5%.
  • One entry per grown tree, depending on its type (see the tree table). Saplings add nothing here.
P(type) = (random entries × random chance of type + tree entries of type) / (random entries + grown trees)

Every mushroom in one harvest is the same type, so this is also the expected share of each type.

2. How many

k = floor(n / 2) amount = clamp(k × (1 or 2, 50/50), 1, 5) average amount = (clamp(k, 1, 5) + clamp(2k, 1, 5)) / 2

So 0–3 trees give 1–2 mushrooms, and 10 or more trees always give 5 (the cap).

3. Quality and price

p = min(1, (n + mossy trees) / 40) ← chance of each upgrade step Normal = 1 − p Silver = p(1 − p) Gold = p²(1 − p) Iridium = p³

The game rolls quality up one step at a time (Normal → Silver → Gold → Iridium) with chance p at each step, stopping at the first failure. Mossy trees are counted as grown Oak/Maple/Pine in range × moss share. Sell prices are the base price × 1.25 (Silver), × 1.5 (Gold) or × 2 (Iridium), rounded down:

4. Timing

A log produces every 4 days, all year round (including winter). The wiki says rainy days "take a day less" but doesn't spell out how several rainy days in one cycle combine. With rain chance r per day, the planner estimates the cycle length as:

days per harvest ≈ 4 − (1 − (1 − r)⁴) ← 4 days minus the chance of at least one rainy day in the cycle

This is an estimate, not an exact model of the game's timer. Totals use a 28-day season and a 112-day year.

Worked example

The log in the diagram above has 6 grown Pines in range, no moss and no rain:

  • Pool: random entries = floor(0.75 × 6) = 4, plus 6 Chanterelle entries, for 10 total. So 60% Chanterelle, and the 4 random entries give 32.3% Common, 5.7% Red and 2.0% Purple.
  • Amount: k = 3, so either 3 or 6 (capped at 5), giving an average of 4 per harvest. At one harvest every 4 days, that's 1 mushroom per day.
  • Quality: p = 6 / 40 = 15%, so 85% Normal, 12.75% Silver, 1.9% Gold, 0.3% Iridium.
  • Value: an average Chanterelle is worth 167.2g, Common 41.8g, Red 78.3g, Purple 261.2g. Weighted by the pool, that's ≈ 123.5g per day, the same figure the planner's tooltip shows for this log.

Adding four more trees to this log (10 total) locks the amount at 5 and raises quality. That's why optimized layouts pack trees tightly around logs.

6. Tree spacing rules

  • Grown trees can't touch, not even diagonally. A seedling won't grow past stage 4 if a grown tree is on any of its 8 surrounding tiles, so the planner never places two grown trees side by side.
  • A stunted sapling must touch at least one grown tree, or it would eventually finish growing.
  • Logs and walkways can go anywhere, including right beside trees.

As a result, a log's 7×7 range holds at most 16 grown trees. With saplings filling the gaps, it can have far more trees in total.

7. Reachability

With walkways on, the planner "floods" outward through empty tiles to find the ones you can walk to, moving up, down, left and right:

  • Normal: the flood starts from every empty tile on the plot's edge. An item counts if it's on the edge or if any of its 8 neighbors is a reachable walkway.
  • Harvest only from walkways: the same flood, but being on the edge no longer counts. Every item needs a reachable walkway beside it.
  • Continuous path: each separate walkway network touching the entrance side is flooded on its own. The planner adds up what each network can reach and keeps only the single best one. Edge items get no special treatment.
  • Console mode: only the 4 directly adjacent tiles count as standing spots (for logs, and for tapped trees if that box is ticked).

8. Target share

Because every log adds random entries to its pool, even a log surrounded by nothing but Oaks can't make only Morels. The best case for one log is two trees of the right type, since that gives the fewest random entries per tree:

MushroomBest treesHighest share
Commonnone / Mahogany / saplings80.75%
Purple2 Mystic68.3%
Morel2 Oak66.7%
Chanterelle2 Pine66.7%
Red2 Maple64.75%

Few trees means few mushrooms, though. At higher tree counts the share settles around 57–59%. So a high target trades gold for purity, and the optimizer handles that trade-off automatically. If you're short of the target, the score drops by 3000 × plot tiles gold per day per 100% of shortfall. That's large enough that reaching the target always comes first.

9. Repeating tiles

For the per-tile figures, the planner treats the tile as repeating forever in every direction. Anything that runs off one edge carries on in the copy next door:

  • Trees near an edge count for logs in the next tile. A log's 7×7 range wraps around to the opposite side of the tile. On a tile narrower than 7 squares, the range can reach the same tree square in two different copies, and each copy counts, just as it would on the farm.
  • Spacing rules apply across edges. A grown tree on the right edge can't sit beside a grown tree on the left edge, because the next copy puts them side by side.
  • Walkways must join up across edges. The planner floods each walkway network across the tile's edges and checks whether it meets itself again one tile over. A network that meets itself going across or down runs on forever as a strip, so you can reach it from the outside of the finished group. A network that meets itself in two different directions joins every tile together. That's what the connected-network option requires. A network that never leaves its tile would be sealed in by the copies around it, so anything that relies on it is unreachable.

The tile's score is its gold per day with copies on every side, calculated exactly as for a fixed plot. It uses the same target-share rule, based on the tile's own mushroom mix.

The preview and the Growing your farm table don't wrap. The planner builds the actual group of copies as an ordinary fixed plot and calculates it normally: logs on the outer edge see fewer trees, and outer edges can be walked in from (unless you chose to harvest only from walkways). That's why a small group earns less per tile than the surrounded figure, and why the gap shrinks as the group grows.

With Find the best tile size, sizes are compared by gold per day per square of land. A 4×6 tile earning 1,800g (75g per square) beats a 6×6 tile earning 2,600g (72g per square), because the same land holds 1.5 of the smaller tiles.

The search method

Even a small plot has far too many possible layouts to check them all, so the planner searches using simulated annealing, followed by a clean-up pass.

  1. Starting layouts. It scores about ten ready-made patterns for each tree type you allowed (plus an empty plot and a plot full of logs), and starts from the best. They include trees on every other tile, rows of trees and logs with walkways between them, and a central path with side branches.
  2. Annealing (about 85% of the search time). On each step it makes one small random change:
    • 55%: set a random tile to a random type,
    • 30%: swap two tiles up to 3 apart,
    • 15%: copy a neighboring tile's type.
    Changes that break the spacing rules are thrown out right away. Improvements are always kept. A change that makes things worse by Δ is kept with chance e^(−Δ/T), where the "temperature" T starts high and falls steadily to near zero. Early on, this lets the search escape layouts that look good but aren't the best. By the end it only accepts improvements. The starting temperature is set by test-running about 150 random changes to see how big a typical change is.
  3. Clean-up (the rest). It visits every tile, tries every allowed type there, and keeps any change that helps, for up to three passes or until time runs out. Finally, it removes any log that can't be reached, since it earns nothing, so it doesn't appear on your shopping list.

Repeating tiles use the same search with wrapped edges: a swap or copy can reach across the tile edge, and the starting layouts include patterns with a walkway along the tile's right edge, bottom edge or both, so the walkways join the next copy. Starting layouts that break the spacing rules across an edge are skipped. Find the best tile size splits the time in two. The first half gives every size a short search. The second half runs a full search on the size that earned the most per square, starting from the best layout found for it.

To keep it fast, a change only recalculates logs within 3 tiles of it. The walkway flood is redone after every change, and the search runs in a background thread so the page stays responsive. The best layout found so far is always the one shown.

It's a heuristic: it finds very good layouts, but there's no guarantee of the single best one. On big plots, try a longer search time or run it twice and keep the better result.

Assumptions & limits

  • Every tile in the plot can hold a tree or a log. Buildings, water and other obstacles aren't modeled. Paint them as empty tiles, or plan a smaller rectangle.
  • Repeating tiles are placed in a straight grid, edge to edge. Staggered placements (like bricks) aren't explored.
  • Trees are assumed to be fully grown. Growing time and the first harvest's delay aren't counted.
  • Moss is a single average share, not tracked per tree. Moss doesn't grow in winter, and picking it removes the quality boost.
  • Rain is an estimate (see Timing).
  • Mahogany sap is taken as the average of its range: 7.5 per day with a Tapper (5–10) and 5.5 with a Heavy Tapper (3–8).
  • Mushroom Trees, Green Rain trees, palm trees and fruit trees can't be placed in the planner.
  • Figures are sale values. The cost of seeds, tappers and crafting materials isn't subtracted.
