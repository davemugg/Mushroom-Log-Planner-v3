📊 Tile study📖 Guide & methods

Layout type

Plot

Logs near a tile's edge count the trees in the neighboring copies, and walkways join up across tile edges. Earnings per tile assume copies on every side.

Normally you can harvest from any of the 8 tiles around an item, and the plot's edges count as reachable from outside.

You can still walk in from any edge, but logs and tapped trees on the edge need a walkway beside them too. Always on with a continuous path.

The plot is treated as fenced in. You walk in at the entrance and only the connected path counts. Items on the edge can't be reached from outside.

A repeated tile has no outside to walk in from, so walkways have to run off the tile's edges and join the next copy. A walkway that stays inside one tile counts as unreachable. With the connected-network option, walkways must join up both across and down, so every tile links to every other.

Trees you can plant

A sapling next to a grown tree never finishes growing. It still counts as a nearby tree, so logs make more mushrooms and better quality. It can't be tapped, though, and only adds Common, Red or Purple mushrooms to the mix.
